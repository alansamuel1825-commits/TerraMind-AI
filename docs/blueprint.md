# **App Name**: VoteChain

## Core Features:

- Secure Login: Students securely log in using their school ID and password.
- Candidate Display: Display candidates for Head Boy and Head Girl with their names, pictures, and vote buttons.
- One-Person-One-Vote: Ensure that each student can only vote once.
- Vote Submission: Submit the student's votes and display a success message.
- Session Reset: Redirect back to the login page after voting.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust and authority, ideal for an election setting.
- Background color: Very light blue (#E8EAF6), near white, for a clean and unobtrusive backdrop.
- Accent color: A vibrant purple (#9C27B0), a neighboring color, adds energy without disrupting the calm, professional feel.
- Font: 'Inter', sans-serif. This font ensures a clean, modern, and highly readable interface suitable for displaying candidate information and instructions clearly.
- Use simple and clear icons for navigation and voting actions.
- Maintain a straightforward, uncluttered layout to minimize confusion during the voting process.
- Use subtle animations to confirm vote submissions.
